## L4 / L3 calculus + pseudo-language conventions (governed by the semantic surface)

For layer intros at **L4** or **L3**, and for `concepts/<slug>.md` pages whose body touches L4/L3 calculus notation, the canonical reference is the **semantic surface** `book/src/design/l4_calculus.md` (§Semantic surface ownership above; user directive 2026-05-27, mid-cycle-006; promoted to active-management surface 2026-06-06). Cite and continue it; do not displace it; **link to its general rules rather than restate them** (the USE+LINK discipline above). Notation throughout L4/L3 layer intros and calculus-touching concept pages:

- **Signatures**: Haskell `::` arrow form — `f :: A -> B -> C`.
- **Records**: TypeScript brace form — `{ field: type }`.
- **Body shapes**: Haskell-style do-notation (`do { let x = e; modify f; pure r }`) and lambda (`\s -> ...`).
- **Fenced**: ` ```text ... ``` ` for code/signatures; ` $$ ... $$ ` math display for reduction rules and small-step semantics.
- **Shape congruence — use NAMED SHAPE GROUPS in dep-map cells + concept pages, not bare `Tensor[N]`** (user directive 2026-06-06; authoritative def `book/src/design/l4_calculus.md` §1.2.1–§1.2.2; memory `project_named_shape_groups_notation`). When you author an L4/L3/L2 dep-map signature cell or a calculus-touching concept page for a shape-generic op (element-local / whole-tensor / whole-tensor-reduce — `axpy`/`dot`/`nrm2`/`scal`/`normalize`/`reciprocal`/`elementwise_product`/…), write the **named shape group** `Tensor[(S: ...)]` (first **binding**) / `Tensor[$S]` (every **use** — the `$` sigil marks a back-reference to a bound group), NO colon before `[` — NOT bare `Tensor[N]` (which is a **rank-1 tensor of length `N`** and silently pins to rank-1). For a domain≠range operator use the two-group form `LinOp[(R: ...), (D: ...)]` (binds both), applied `-> Tensor[$D] -> Tensor[$R]`; a square operator is `LinOp[(S: ...), $S]`. **Reserve `Tensor[N]` for genuinely-flat rank-1 dof-vectors** — KEEP it at **L1 / L0** (Palace `Vector` is rank-1) and for genuine rank-1 lists at any layer (eigenvalue list `Tensor[K]`, projection-coeff `Tensor[m]`). Complex renderings convert the shape to `(S: ...)` and preserve the `complex` annotation as written (`Tensor[(S: ...), complex]`). Keep a dep-map cell consistent with its owning chapter's signature.
